What this is

The domain

trumper.go is a Web3 domain, not a rented web address. It is a record on a blockchain. No registrar, no renewal invoice, no company that can take it back.

Two things that buys you:

  • One name instead of a wallet address. Wallet records can be attached to the domain, so people send to a name they can read rather than a 44-character string they have to trust.
  • Hosting nobody can pull. This page is built to be pinned to IPFS and served from the domain itself. There is no server to take down.
